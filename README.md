# Snappy AP80 Pro Max

A clean, high-contrast **Rockbox theme for the Hidizs AP80 Pro Max**, designed for its 360 × 640 portrait display.

> **Japanese character compatible.**

[**Download v1.0.0**](https://github.com/mr-f0xx/Snappy-AP80-Pro-Max/releases/download/v1.0.0/Snappy_AP80_ProMax.zip)

## What it is

Snappy AP80 Pro Max is a portrait Rockbox skin for the **Hidizs AP80 Pro Max** music player. The browsable `.rockbox` directory in this repository contains the theme files ready to copy to a Rockbox player.

## Install

Copy the `.rockbox` directory from this repository to the player’s storage, merging it with the existing `.rockbox` directory. Then select the Snappy AP80 Pro Max theme from Rockbox’s theme settings.
